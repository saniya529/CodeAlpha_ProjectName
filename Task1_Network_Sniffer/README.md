# Basic Network Sniffer

## Overview
This project is a basic network sniffer developed using Python and Scapy. It captures IP packets and displays basic packet information for network analysis.

## Features
- Captures 10 IP packets.
- Displays Source IP and Destination IP.
- Identifies TCP and UDP protocols.
- Shows packet size in bytes.
- Displays IP version and TTL.
- Shows source and destination ports.
- Provides basic packet analysis.
- Displays packet layers using Scapy.
- Calculates payload size without displaying private payload content.
- Identifies TCP, UDP, ICMP, and IGMP protocols.
## Technologies Used
- Python
- Scapy
- Npcap

## How to Run
Run the following command in PowerShell:

python network_sniffer.py

## Output
The program displays packet details such as IP addresses, protocol, packet size, TTL, and transport ports.

## Disclaimer
This tool is intended for educational purposes and should only be used on networks you own or have permission to monitor.
