# Basic Network Sniffer

## Project Overview
This project is a basic network sniffer developed using Python and Scapy.

## Objective
The objective is to capture and analyze basic network packet information.

## Technologies Used
- Python 3.14
- Scapy 2.8.0
- Npcap
- Visual Studio Code

## Features
- Captures 10 network packets.
- Displays Source IP Address.
- Displays Destination IP Address.
- Identifies TCP and UDP protocols.
- Displays packet size in bytes.

## How to Run
1. Install Python.
2. Install Scapy using:

python -m pip install scapy

3. Install Npcap on Windows.
4. Run the program:

python network_sniffer.py

## Result
The program successfully captured 10 packets and displayed their source IP, destination IP, protocol and packet size.

## Conclusion
The project demonstrates basic network packet capturing and analysis using Python and Scapy.
