# Task 1 - Basic Network Sniffer

## Objective
To capture and analyze basic network packet information.

## Technologies Used
- Python 3.14
- Scapy 2.8.0
- Npcap
- Visual Studio Code

## Features
- Captures 10 network packets.
- Displays source IP address.
- Displays destination IP address.
- Identifies TCP and UDP protocols.
- Displays packet size.

## Testing
The program successfully captured 10 packets and displayed their basic information.

## Conclusion
This project demonstrates basic network packet capturing and analysis using Python and Scapy.
