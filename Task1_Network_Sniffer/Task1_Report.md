# Task 1 - Basic Network Sniffer Report

## Objective
To understand basic network traffic and identify packet information using Python.

## Tools Used
- Python
- Scapy
- Npcap
- Visual Studio Code

## Implementation
A basic network sniffer was developed using Python and Scapy. The program captures 10 IP packets and analyzes their basic metadata.
The program also identifies packet layers such as Ethernet, IP, TCP, and UDP.
It calculates payload size in bytes without displaying private payload content.
The program identifies TCP, UDP, ICMP, and IGMP protocols.

## Information Analyzed
- Source IP Address
- Destination IP Address
- Protocol (TCP/UDP/ICMP/IGMP)
- Packet Size
- IP Version
- TTL (Time To Live)
- Source Port
- Destination Port

## Testing
The program was executed successfully and captured 10 packets. Packet information was displayed in the PowerShell terminal.

## Result
The network sniffer successfully captured and analyzed basic packet metadata.

## Conclusion
This task helped me understand basic packet structure, IP addressing, transport protocols, and how network traffic can be monitored for educational purposes.
