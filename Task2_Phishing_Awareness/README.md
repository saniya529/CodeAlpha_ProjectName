# Phishing Awareness Training

## Project Overview
This project explains phishing attacks, common warning signs, and ways to stay safe online.

## Objective
To educate users about phishing scams and improve online safety awareness.

## Topics Covered
- Types of phishing
- Warning signs of phishing
- Social engineering
- Real-world phishing examples
- Safe internet practices
- Protection of personal information

## Project Files
1. `phishing_awareness.md` – Complete training content.
2. `Phishing_Awareness_Training.pptx` – Training presentation.
3. `quiz.html` – Interactive phishing awareness quiz.

## How to Run the Quiz
1. Open the `Task2_Phishing_Awareness` folder.
2. Double-click `quiz.html`.
3. Answer all five questions.
4. View your final score.
