# Secure Coding Review

## Project Overview
This project demonstrates basic secure coding practices using Python.

## Objective
To understand how sensitive information, especially passwords, can be handled securely.

## Technologies Used
- Python 3.14
- hashlib
- hmac
- os

## Security Features
- Password hashing using PBKDF2-HMAC-SHA256.
- Random salt generation.
- Password verification.
- Secure password comparison.
- Password is not displayed during input.

## Testing Result
The program successfully processed a test password and verified it.

## Conclusion
This project demonstrates basic password security techniques and secure coding practices using Python.
