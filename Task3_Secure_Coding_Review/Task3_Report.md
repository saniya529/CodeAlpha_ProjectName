# Task 3 – Secure Coding Review

## 1. Introduction
This project demonstrates secure password handling using Python.

## 2. Objective
To understand password hashing, random salt generation, and password verification.

## 3. Tools Used
- Python 3.14
- hashlib
- hmac
- os

## 4. Implementation
The program uses PBKDF2-HMAC-SHA256 to generate a password hash with a random salt.

## 5. Testing
The program was tested with a sample username and password. Password verification was successful.

## 6. Conclusion
The project demonstrates basic secure coding practices for protecting passwords.
