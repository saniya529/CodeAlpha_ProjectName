# Network Intrusion Detection System

## Project Overview
A basic Python-based system that detects suspicious activities in simulated network events.

## Objective
To understand how a simple intrusion detection system identifies unusual activity.

## Technologies Used
- Python 3.14
- collections module

## Features
- Detects repeated failed login attempts.
- Identifies unusual port activity.
- Displays security alerts.
- Uses simulated network events for testing.

## Testing Result
The program successfully detected repeated failed logins and unusual port activity.

## Conclusion
This project demonstrates basic network intrusion detection using Python.
