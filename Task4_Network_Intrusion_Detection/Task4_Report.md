# Task 4 – Network Intrusion Detection System

## 1. Introduction
This project demonstrates a basic Network Intrusion Detection System using Python.

## 2. Objective
To identify suspicious activities in simulated network events.

## 3. Tools Used
- Python 3.14
- collections module

## 4. Implementation
The program checks simulated network events and detects repeated failed login attempts and unusual port activity.

## 5. Testing
The program successfully detected:
- Three repeated failed login attempts.
- Unusual activity on port 23.

## 6. Conclusion
This project demonstrates basic intrusion detection concepts using Python and simulated data.
